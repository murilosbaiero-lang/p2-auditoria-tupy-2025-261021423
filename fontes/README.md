# Fontes públicas

O arquivo `fontes.csv` registra emissor, versão ou período, data de publicação, data de acesso, páginas utilizadas, URL e finalidade de cada fonte.

As demonstrações financeiras de 2025 fornecidas pelo site de Relações com Investidores foram conciliadas com a DFP V1 arquivada na CVM em 19 de março de 2026. Isso atende à orientação de usar CVM e B3 sem desprezar a cópia corporativa: a CVM é a referência de protocolo e a B3 confirma cadastro, ticker e listagem; a versão do RI facilita a leitura do relatório anual completo.

Os PDFs não precisam ser instalados no computador para reproduzir os scripts da base sintética. Quando uma cópia local não estiver presente, use as URLs oficiais da matriz de fontes. Nenhum site de terceiros é usado para sustentar saldos ou requisitos técnicos.

As páginas citadas no dossiê são as páginas do PDF ou as páginas impressas identificadas no próprio documento. Para a Nota 13, por exemplo, são usadas as páginas 46 a 48 das notas explicativas, correspondentes às páginas 46 a 48 do arquivo anual conforme sua numeração visível.
